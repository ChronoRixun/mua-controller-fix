**New: Discord Rich Presence.** With the Discord app running, your Discord profile now shows what you're playing: the area and your hero (for example *Latveria: Urban Warfare · Playing as Wolverine*), the game's picture and the time played. It's on by default and needs no setup.

**Supports:** Marvel: Ultimate Alliance (2016 PC) and Marvel: Ultimate Alliance 2 (2016 PC).

**Install:** download `mua-controller-fix-v1.1.0.zip` below, then copy `dinput8.dll` into the folder that contains `Marvel.exe` or `Alliance.exe`, replacing the old one. **Uninstall:** delete it. If you use Ultimate Legends, it installs the new version for you.

**How it works:** both games already write a status line for Steam's friends list ("Playing *area* As *hero*", "In the Main Menu."). The fix reads it as the game hands it to Steam, passes the call on unchanged, and shows the same text on Discord, so it reads the same in both games without digging through game memory. The games write that line once for each of the four player slots, so on Steam an empty slot's "Watching someone else play." always replaced yours. Discord gets player 1's line.

**What's shared:** only the area, player 1's hero and the time since the game started, sent to the Discord app on your own PC. No player names, no PC, network or account details, and nothing about online lobbies. To switch it off or hide the area or the hero, use `[Discord]` in `mua-controller-fix.ini` ([details](https://github.com/ChronoRixun/mua-controller-fix#-discord)).

**Controller fix:** unchanged from 1.0.0.

Tested on Windows 11 with the Discord desktop app, in both games. If the presence doesn't show, please open an issue with your `mua-controller-fix.log`; its `discord:` lines say what happened.
