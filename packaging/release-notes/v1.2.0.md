**New: a mods folder.** Mods go in folders of their own under `mods`, next to the game's `.exe`, laid out like the game folder. The fix uses a mod's file in place of the game's, so the game's own files are never overwritten and switching a mod off is one line in `mods\load-order.txt` (`+Name` on, `-Name` off, later lines win). Folders the list doesn't name load after the listed ones, so a mod copied in by hand just works. If you use Ultimate Legends, its Mods section manages the same folder and list.

**Supports:** Marvel: Ultimate Alliance (2016 PC) and Marvel: Ultimate Alliance 2 (2016 PC).

**What a mod can replace:** any file the game loads: costumes and models, textures, maps, animations, data (stats, powers, fight styles, missions, text), menus, movies and sounds, including the files inside the game's encrypted `.bin` archives. A mod's file takes the path the game uses for it, the archive's name first: `actors.bin`'s `0301.igb` (Wolverine in MUA) goes in `mods\My Mod\actors\0301.igb`. `[Debug] LogFiles=1` in `mua-controller-fix.ini` lists every file the game looks for under those names ([details](https://github.com/ChronoRixun/mua-controller-fix#what-a-mod-can-replace)).

**How:** the games look every file up in their `.bin` archives before they ask Windows for it. For a file a mod has, the fix makes that lookup come back empty, so the game opens the file from disk and gets the mod's copy; everything else loads as before. That one change to the game's code is made only when the code matches the retail Steam build (after Steam's own decryption of it has run); on any other build the archives stay as they are and `mua-controller-fix.log` says why. With no `mods` folder, nothing about the game's file access changes.

**Install:** download `mua-controller-fix-v1.2.0.zip` below, then copy `dinput8.dll` into the folder that contains `Marvel.exe` or `Alliance.exe`, replacing the old one. **Uninstall:** delete it; mods in the `mods` folder stop loading with it. If you use Ultimate Legends, it installs the new version for you.

**Controller fix and Discord presence:** unchanged from 1.1.0.

Tested on Windows 11 in both games with files from the games' own archives: in MUA2 a mod's `actors\1501.igz` gave Iron Man his New Avenger armour in a level and a mod's `data\richpresence.xmlb` renamed the level in the status line; in MUA a mod's `ui\models\m_logo_alliance.igb` changed the title screen's logo and a mod's `data\RichPresence.engb` changed the status line; in both, a mod's movie replaced the Activision logo. If a mod doesn't load, please open an issue with your `mua-controller-fix.log`.
