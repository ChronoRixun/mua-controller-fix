First release. Drop `dinput8.dll` into your game folder and your Xbox controller's buttons match the on-screen prompts.

**Supports:** Marvel: Ultimate Alliance (2016 PC) and Marvel: Ultimate Alliance 2 (2016 PC).

**Install:** download `mua-controller-fix-v1.0.0.zip` below, then copy `dinput8.dll` into the folder that contains `Marvel.exe` or `Alliance.exe`. **Uninstall:** delete it.

**What it fixes:** the games only recognise a handful of older Xbox controllers by product ID. Anything else, such as an Xbox Wireless Controller over Bluetooth, gets a generic layout with scrambled face buttons (the prompt says A, you have to press X). The fix presents XInput pads as a wired Xbox 360 controller and feeds the game that controller's exact input layout.

Tested with an Xbox Wireless Controller over Bluetooth on Windows 11, in both games. Other XInput pads should work; please open an issue with your `mua-controller-fix.log` if yours doesn't.

This DLL was built and packaged by GitHub Actions from the tagged source.
